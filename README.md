# Jatin Chhabra — AI & Machine Learning Engineer Portfolio

A premium, futuristic portfolio website built with **Next.js 14**, **TypeScript**, **TailwindCSS**, and **Framer Motion**.

## About

**Jatin Chhabra** is a Data Science, Artificial Intelligence & Machine Learning Engineer passionate about building intelligent systems that solve real-world problems. Specializing in end-to-end AI solutions combining Machine Learning, Deep Learning, Generative AI, LLMs, NLP, Computer Vision, and modern software engineering.

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: TailwindCSS
- **Animations**: Framer Motion
- **3D**: Three.js + React Three Fiber
- **Smooth Scroll**: Lenis
- **Icons**: Lucide React

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the portfolio.

## Build

```bash
npm run build
npm run start
```

## Features

- Animated dark futuristic theme with aurora gradients
- Premium floating glass navbar with hide/show on scroll
- Interactive 3D AI profile card with tilt effect
- Fully animated sections with Framer Motion
- Custom premium cursor with glow trail
- Smooth scroll with Lenis
- Three.js animated particle background
- Responsive across all screen sizes
- SEO optimized with Open Graph & structured data
- Scroll progress indicator
